S-TECH HTML E-COMMERCE WEBSITE

1. Extract the folder.
2. Open index.html in Chrome/Edge.
3. No XAMPP or database is required.
4. Edit products inside script.js.
5. Edit colors/design inside style.css.
6. The cart uses browser LocalStorage.

This is a frontend/demo e-commerce website. For real orders, login, database,
admin panel and payment gateway, connect it to a backend such as PHP + MySQL.
